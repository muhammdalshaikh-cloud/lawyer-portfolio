# موقع محمد بن عبدالواحد آل الشيخ - محامٍ متخصص في القضايا العمالية

## نظرة عامة

موقع إلكتروني احترافي يعرض خدمات محامٍ متخصص في القضايا العمالية والاستشارات القانونية. يتضمن الموقع سيرة ذاتية شاملة، معلومات الخبرة، والخدمات المقدمة، مع نماذج تفاعلية لطلب الخدمات.

## المميزات الرئيسية

### 1. **الصفحة الرئيسية (Hero Section)**
- عنوان جذاب يعكس التخصص والاحترافية
- أزرار سهلة الاستخدام للتنقل إلى الخدمات والتواصل
- تصميم استجابي يتناسب مع جميع الأجهزة

### 2. **قسم من أنا**
- نبذة احترافية عن المحامي
- معلومات الاتصال الكاملة (بريد، جوال، لينكد إن)
- إحصائيات توضح الخبرة (عدد الدعاوى، الاستشارات، العقود)

### 3. **قسم الخدمات**
- **تولي قضية عمالية:** مع نموذج طلب تفاعلي
- **استشارة عمالية:** مع نموذج طلب تفاعلي
- **خدمات قانونية أخرى:** مع رابط واتس آب مباشر

### 4. **نماذج الطلب**
- استبانة شاملة لطلب الخدمات
- حقول مخصصة لنوع القضية والوصف التفصيلي
- خيار لإرفاق المستندات

### 5. **قسم الخبرة والتعليم**
- تفاصيل الخبرة العملية الكاملة
- المؤهلات التعليمية
- الشهادات والرخص المهنية

### 6. **خريطة جوجل**
- موقع المحامي على الخريطة التفاعلية
- يمكن تحديثها بإحداثيات دقيقة

### 7. **قسم التواصل**
- روابط مباشرة لجميع وسائل التواصل
- البريد الإلكتروني
- الجوال
- الواتس آب
- لينكد إن

## التصميم والألوان

- **اللون الأساسي:** أزرق داكن (#1a3a52) - يعكس الاحترافية والثقة
- **اللون الثانوي:** أزرق فاتح (#2c5aa0)
- **اللون الذهبي:** (#d4af37) - للعناصر البارزة والأزرار
- **الخط:** Segoe UI و Roboto - خطوط احترافية وسهلة القراءة

## التكنولوجيا المستخدمة

- **React 19:** مكتبة JavaScript لبناء واجهات المستخدم
- **Vite:** أداة بناء سريعة وحديثة
- **CSS3:** تصميم استجابي وحديث
- **JavaScript ES6+:** لتحسين التفاعلية

## البنية الأساسية للمشروع

```
lawyer-portfolio/
├── src/
│   ├── App.jsx          # المكون الرئيسي
│   ├── App.css          # أنماط التصميم
│   ├── index.css        # الأنماط العامة
│   └── main.jsx         # نقطة الدخول
├── public/              # الملفات الثابتة
├── index.html           # الصفحة الرئيسية

```

## كيفية الاستخدام المحلي

### المتطلبات
- Node.js (الإصدار 16 أو أحدث)
- pnpm أو npm

### التثبيت والتشغيل

```bash
# الانتقال إلى مجلد المشروع
cd lawyer-portfolio

# تثبيت المكتبات
pnpm install

# تشغيل خادم التطوير
pnpm dev

# الوصول إلى الموقع
# http://localhost:5173
```

### البناء للإنتاج

```bash
# بناء النسخة النهائية
pnpm build

# معاينة النسخة المبنية
pnpm preview
```

## تخصيص الموقع

### تحديث المعلومات الشخصية

قم بتحرير ملف `src/App.jsx` وحدّث:
- الاسم والمعلومات الشخصية
- رقم الجوال والبريد الإلكتروني
- رابط الواتس آب
- تفاصيل الخبرة والتعليم

### تغيير الألوان

قم بتحرير ملف `src/App.css` وعدّل متغيرات الألوان في القسم `/* Root Variables */`

### إضافة صور

ضع الصور في مجلد `public/` وأضف مسارها في الكود
